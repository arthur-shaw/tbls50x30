# Make plot use table

Make plot use table

## Usage

``` r
plot_use(plot_df, cases, plot_use_var, group_var)
```

## Arguments

- plot_df:

  Data frame of plots.

- cases:

  Data frame of cases to include in analysis.

- plot_use_var:

  Character. Name of plot use column.

- group_var:

  Name of grouping variable column (e.g., team, region, etc.).

## Value

gt table object
