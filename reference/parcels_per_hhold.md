# Make parcels per household table

Make parcels per household table

## Usage

``` r
parcels_per_hhold(parcel_df, cases, use_var = NULL, use_vals = NULL, group_var)
```

## Arguments

- parcel_df:

  Data frame of parcels.

- cases:

  Data frame of cases to include in analysis

- use_var:

  Character. Parcel use variable

- use_vals:

  Numeric vector. Values that correspond to an agricultural use

- group_var:

  Character. Grouping variable

## Value

gt table object
