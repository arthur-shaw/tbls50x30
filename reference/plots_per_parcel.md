# Make plots per parcel table

Make plots per parcel table

## Usage

``` r
plots_per_parcel(parcel_plot_df, cases, parcel_id_var, group_var)
```

## Arguments

- parcel_plot_df:

  Data frame of parcel-plots.

- cases:

  Data frame of cases to include in analysis.

- parcel_id_var:

  Character. Name of parcel ID column.

- group_var:

  Character. Name of grouping variable column (e.g., team, region,
  etc.).

## Value

gt table object
